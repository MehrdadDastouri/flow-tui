# flow-tui

Real-time microstructural order flow imbalance (OFI) and depth telemetry in your terminal.

## Features
- Real-time Level-2/Level-3 Order Book Depth Ingestion
- Live Order Flow Imbalance (OFI) Computation
- Cumulative Volume Delta (CVD) Tracking
- High-FPS Async Terminal UI powered by Textual

## Quick Start
git clone [https://github.com/MehrdadDastouri/flow-tui.git](https://github.com/MehrdadDastouri/flow-tui.git)
cd flow-tui
pip install -e .
flow-tui
